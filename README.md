# 📊 Sales Forecasting Dashboard Tableau

## 📌 Project Overview

This project focuses on analyzing a sales dataset to generate meaningful insights into customer purchasing behavior. It involves data processing using SQL and creating interactive dashboards using Tableau for better decision-making.

---

## 🛠️ Tools & Technologies


* **Tableau** – Data visualization and dashboard creation
* **Microsoft Excel** – Dataset handling and preprocessing

---

## 📊 About Tableau

Tableau is a powerful data visualization and Business Intelligence (BI) tool used to analyze and present data in an interactive and visual format. It allows users to connect to multiple data sources, create dashboards, and gain real-time insights for decision-making.

---

## 🎯 Project Objectives

* Analyze customer purchase behavior
* Generate business insights from sales data
* Build interactive dashboards for visualization
* Perform data-driven decision-making

---

## ⚙️ Key Features


* Data visualization using Tableau
* Creating interactive dashboards
* Applying filters for better insights

---

## 📈 Visualizations Created

* Annual Revenue Analysis
* Customer Distribution by Country
* Sales by Product Line
* Monthly Sales Trends
* Revenue by Country and Status
* Sales Distribution
